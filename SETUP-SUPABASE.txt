VALLEY BITES — SUPABASE ORDER SETUP

The website files have been updated so orders are saved to your Supabase public.orders table before WhatsApp opens.

IMPORTANT:
1. Open script.js.
2. Find:
   const SUPABASE_PUBLISHABLE_KEY = "PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE";
3. Replace only the text inside the quotes with your Supabase PUBLISHABLE key.
4. NEVER use the Supabase secret/service-role key in script.js.
5. Your existing RLS INSERT policy must remain enabled:
   Allow customers to create orders
6. Upload all website files to GitHub and deploy to Vercel.

Current table expected by the script:
- id
- created_at
- customer_name
- phone
- order_type
- address
- total_amount

How orders are stored:
- Normal WhatsApp order: order_type = WhatsApp
- Location order: order_type = WhatsApp + Location
- Item list is stored in the address field because the current table does not yet have an items column.

If you later add an items (jsonb/text) column, the script can be upgraded to store the order items in that dedicated column.
